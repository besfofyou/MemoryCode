# 2026-10-26

## SkillForge 进化空转问题修复

**诊断**：`.mini-code/memory/` 下 16 个 skill 全部卡在 trial，6 个进化周期全空。根因：CLI 阈值过高（promoteMinUsage=5，实际最高 usage 4）+ trial 检索按 usage 严格升序摊薄曝光 + 蒸馏每 3 回合无限新增稀释池子 + 5 条记忆类近重复 skill 分流 usage。

**修复（已通过 357 全量测试 + lint + 生产数据模拟验证）**：
- `skill-evolution.ts`：CLI_EVOLUTION_PRESET 下调（promote 5→3、warmup 5→3、retire 12→10、stabilize 20→15、mutate 8→6）；maybeEvolve 新增 step 0 合并存量近重复（败者统计并入胜者后转墓碑，reason='merged'）。
- `skill-bank.ts`：新增 `mergeNearDuplicates()`（仅当重复对至少一方为 trial；胜者按生命周期→fitness→usage→文本长度选出；谱系重接）、`reinforce()`（重复提取记为一次成功使用）；rank() 的 trial 探索槽改为权重 (0.2+相关性)/(1+usage) 的不放回加权采样，RetrieveOptions 支持注入 random。
- `distiller.ts`：findNearDuplicate 命中时改为 reinforce 而非直接丢弃。
- `runtime.ts`：新增 `shouldSkipSkillDistill()` 闸门——delta < 3 条消息 / 池子 ≥ 90% 容量 / trial ≥ 8 且占比 ≥ 60% 时跳过蒸馏且不推进游标；常量在 constants.ts SKILL_BANK_CONFIG。
- 测试：skill-bank.test.ts +3 个 describe，skill-evolution.test.ts +1 合并晋升集成测试，新增 distill-gate.test.ts（3 用例）。

**验证**：用真实 skill-bank.json 副本模拟第 30 回合进化，5 个 skill 成功 promote 为 active（修复前全空）。

**注意**：mergeNearDuplicates 的纯 token 相似度抓不住措辞差异大的中文近重复（实测 5 条记忆类 skill 未被合并，靠阈值下调晋升）；如需更强的合并可引入 embedding 相似度。
